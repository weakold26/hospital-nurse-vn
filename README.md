# 새벽 두 시, 3층 병동

> 첫 당직, 첫 실수, 그리고 새벽 세 시의 복도.
> 병동 실습 5일 동안, 새벽을 함께 세는 두 간호사와의 이야기.

브라우저에서 바로 실행되는 비주얼 노벨입니다. 설치도, 계정도 필요 없습니다.
순수 HTML · CSS · JavaScript — 외부 라이브러리 없이 동작합니다.

**▶ 플레이: https://weakold26.github.io/hospital-nurse-vn/**

## 등장인물

| | |
|---|---|
| **정하람** (29, 병동 4년차 간호사) | 말이 짧고 손이 정확한 사람. 다정함을 말이 아니라 순서로 보여 준다. 야간 병동의 4년은, 그녀에게 조용한 새벽과 몇 개의 잊지 못할 이름을 남겼다. |
| **오세린** (23, 응급실 1년차 간호사) | 2주간 병동 야간 지원 근무. 계단을 두 칸씩 오르고, 야식을 두 그릇 챙긴다. 제일 밝은 사람이 제일 먼저 지치는 자리에 서 있다. |

주인공은 치과대학 4학년, 구강악안면외과 병동 실습 마지막 주.

## 플레이 방법

- **화면 클릭 / Space / Enter** — 대사 진행 (출력 중이면 즉시 전체 표시)
- **선택지** — 번호 버튼 또는 화면의 선택지 터치
- **로그(L)** — 지나간 대사 다시 보기
- **자동(A)** — 대사가 끝나면 자동으로 진행
- **스킵(S)** — 선택지를 만날 때까지 빠르게 넘김
- **저장 / 불러오기** — 슬롯 3개 + 자동 저장 (`localStorage`)
- **설정** — 글자 속도(느리게/보통/빠르게/즉시), 배경음·효과음
- 모바일(iPhone) 세로 화면에 맞춰 반응형으로 동작합니다.

## 엔딩

14개의 선택지와 두 사람의 호감도에 따라 **5종**의 엔딩이 있습니다.
타이틀 화면의 「엔딩 도감」에서 수집 현황을 볼 수 있습니다.

| | 결말 |
|---|---|
| 01 | **3층의 아침** — 하람 · 해피 엔딩 |
| 02 | **잘 부탁합니다, 선배님** — 하람 · 노멀 엔딩 |
| 03 | **야식은 두 그릇** — 세린 · 해피 엔딩 |
| 04 | **먼저 가는 사람** — 세린 · 노멀 엔딩 |
| 05 | **우리 모두의 라운드** — 히든 · 우정과 일 엔딩 |

## 구성

```
index.html              무대 · 타이틀 · 모달 마크업
css/style.css           4레이어 무대, 대사창, 선택지, 반응형
js/engine.js            엔진: 타자기·분기·호감도·세이브·자동·스킵
js/audio.js             WebAudio 로 만드는 배경음과 효과음 (외부 음원 없음)
src/data/scenario.json  시나리오 405개 대사 노드 · 선택지 14개 · 엔딩 5종
assets/img/             배경 4종 · 캐릭터 스탠딩 8종 (WebP)
tools/                  시나리오 빌더 · 전수 시뮬레이터 · 자산 빌더 · 모바일 미리보기
```

- 무대는 배경(크로스페이드 2겹) → 캐릭터(표정 전환) → 이펙트(부유 입자·비네트·그레인) → UI 4레이어로 구성됩니다.
- 배경음은 코드로 합성한 앰비언트 패드이며, 장면마다 조(day / night / warm / tense)가 바뀝니다.
- 캐릭터 표정은 기본 이미지에서 표정만 바꿔 생성해 인물의 일관성을 유지했습니다.

## 검증

```bash
python3 tools/simulate.py     # 도달 불가 노드 · 끊긴 링크 · 막다른 길 · 엔딩 도달 · 문장 점검
python3 tools/scenario_build.py   # 시나리오 모듈 → JSON
```

시뮬레이터는 호감도와 플래그를 포함한 모든 상태를 탐색해 5개 엔딩에 모두 도달하는지 확인합니다.
